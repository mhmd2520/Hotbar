Design explorer · Claude Code project launcher · Windows 11

One keystroke to any project, Claude already running.

Press Ctrl+\ anywhere, see your project list as a semi-transparent overlay, hit a number, and get a full-screen PowerShell in that folder with claude running. Every interface below works in the page, so you can compare them before anything gets built. What you pick is saved in this browser. Use My picks (bottom right) to copy your choices back to Claude.

01

What I think of the idea

It's worth building. It removes a step you repeat dozens of times a day (open terminal → cd → claude), and it's small enough to finish. What decides whether you keep using it is reliability: the overlay has to appear instantly on every press and never open the wrong thing.

Why it works

Muscle memory beats menus. With numbers fixed to projects, Ctrl+\ 1 becomes a reflex you stop thinking about. The overlay is mostly there for learning the numbers and for the "Other…" case.

It can grow into a project hub. Once the launcher knows your projects, it can also show the last Claude session, git state, whether a session is already running, and notify you when Claude finishes.

The game-menu layout suits it. Big stacked buttons and a numbered hotbar read well at a glance. Kept flat (no textures), they stay crisp at any scale, render instantly, and can be re-skinned from Arcade to Fluent Glass with one setting.

My recommendation: the Game Menu overlay with type-to-filter built in, plus Hotbar or Alt-Tab Strip as alternative layouts. Build it with Tauri 2 (web UI, about a 5 MB app, official global-hotkey, tray and autostart plugins). Before that, spend one evening on a 40-line AutoHotkey v2 version to find out if the habit sticks (section 07).

Reliability traps to design around

HOTKEY
Ctrl+\ is "Split editor" in VS CodeA global hook takes it from every app. Either keep a pass-through list (VS Code → send the key through) or pick a combination nothing else uses. Options are in section 06.
ADMIN
Hotkeys stop working over elevated windowsWindows' UIPI blocks input to a non-admin app while an admin window is focused. Start the launcher from Task Scheduler with "Run with highest privileges".
SPEED
Cold start makes it feel slowKeep it in the tray with the window already rendered and hidden, so the hotkey only shows it (<50 ms). Never spawn the process on each press.
DUPES
Opening the same project twiceGive every window a fixed title (--title "RailPair" --suppressApplicationTitle). If that window exists, focus it instead. ⇧+Alt forces a new one.
QUOTES
-d "D:\" breaks the command lineA trailing \" escapes the closing quote in Windows argument parsing. Pass D:\ unquoted, or pass arguments as an array (which Tauri/Rust does for you).
F11
"Full screen" vs "maximized"wt --fullscreen hides the tab bar and taskbar, so it looks great but is easy to lose track of. Try both in the Launch tab of the playground.

    06
    How you trigger it
    
  
    You can enable several of these at once. My suggestion is Ctrl+\ as the main trigger, with a VS Code pass-through, plus a blind chord: Ctrl+\ then 2 within ~300 ms opens project 2 before the overlay even draws, and the overlay only appears if you pause.

    09
    Roadmap
    
  
    Each phase is something you can use day to day, so the order can change at any point.
    
  
    
    
    Phase 0 · 1 evening
    Prove the habit
    • Install AHK v2 from D:\AHK\Software
    • 40-line script in section 07
    • Ctrl+\ → native menu → number → Claude
    • Focus an existing window instead of duplicating
    
    
    Phase 1 · weekend
    MVP overlay
    • Tauri 2 tray app, hidden pre-rendered window
    • Blockcraft UI + Other…
    • config.json with your 6 projects
    • Autostart, single instance, elevated task
    
    
    Phase 2 · ~1 week
    Make it yours
    • Settings editor (add, reorder, color)
    • Vibe packs + transparency/blur
    • Open/select gestures + sounds
    • Type-to-filter, Hotbar skin
    
    
    Phase 3 · ~1 week
    Project hub
    • Last session + recent prompts
    • Git branch / dirty badge
    • Running ● / idle ○ status
    • Claude hook → toast → focus
    • Multi-open in tabs, pre-commands
    
    
    Phase 4 · polish
    Ship it
    • Final name + OpenRouter logo set
    • Installer (MSI/NSIS via Tauri)
    • 2nd keyboard bridge (AHI)
    • Wow extras: 3D mode, voice
